# Факторы Яндекса для workevent.ru

Публичной формулы нет. Ниже — рабочие группы, как их применяет оператор к каталогу деловых событий. Сайт: ИКС 10, коммерческий геозависимый интент, конкурент-витрина Expomap.

## 1. Понимание запроса

- Классификация: информационный / коммерческий / навигационный / геозависимый.
- «конференции в москве» = коммерческий + гео. Ждут календарь с датами, не эссе.
- «как выбрать конференцию» = информационный. Блог/Дзен, не вторая витрина.
- «workevent» = навигационный. Бренд обязан открываться первым.
- YATI и наследники сопоставляют блоки: даты, площадки (Экспоцентр, Крокус), отрасли, CTA. Ключ в каждом абзаце не помогает.
- Ассоциации Wordstat («афиша», «куда сходить») — чужой интент. См. `seo-wordstat`.

## 2. Текст

- Уникальность относительно топа, не «уникальность биржи».
- Полнота: топ отвечает «когда / где / для кого / как попасть». Страница без ближайших дат проигрывает.
- Баден-Баден: шаблонные простыни на 80 городах, «страница собрана», переспам ключа.
- Голос: `.cursor/rules/seo-content-lint.mdc`. Линт перед сидом.
- Title/H1 канона не крутить, если URL уже в топ-15.

## 3. Коммерция (главный проигрыш каталога)

Яндекс оценивает «можно ли получить услугу здесь». Для каталога услуга = выбрать событие и заявка.

Обязательный набор:

- Ширина витрины на горизонте 30–60 дней vs топ-3 (Expomap, TimePad-календари).
- На карточке: дата, город, площадка, отрасль, организатор, цена или «регистрация», кнопка заявки.
- Свежесть: прошедшие не выглядят как актуальные.
- Фильтры, которые работают (город, отрасль, даты), не пустые пресеты.
- Контакты, юрлицо (ИНН/ОГРН), политика.
- Яндекс.Бизнес: NAP = сайт. Карточка заведена руками 2026-08-20.
- Отзывы с именем и датой. Фейк хуже нуля. Разметка Review только если отзывы реально на странице.

Пустые категории в индексе бьют ассортимент сильнее, чем «мало текста».

## 4. Поведение

Считается в зоне видимости (примерно топ-20–30). Ниже — почти нет сигнала.

- CTR сниппета: title, favicon, sitelinks, даты в сниппете.
- Last click: ушёл из поиска после визита.
- Pogo-sticking: клик → назад → другой сайт. Типично, если карточек мало или они пустые.
- Глубина и время: каталог должен вести на карточку и заявку, не в тупик.
- Метрика (счётчик 99029501) — вход для обучения. Цели: `event_apply`, `newsletter_subscribe`, `organizer_goto`.
- Бренд в поиске и прямые заходы стабилизируют хост.

Легальный ПФ: лучше витрина, лучше сниппет, живые люди из Telegram/Дзен/Директа. Накрутка — вето, см. gray.md.

## 5. Ссылки и цитирование

После Минусинска вес *аренды* упал. Вес *упоминаний с тематических живых сайтов* остался.

Иерархия для Workevent:

1. Сайт организатора → карточка события (лучший анкор: название события или бренд).
2. Отраслевые СМИ, ассоциации, вузы.
3. Платные статьи на площадках с живым трафиком.
4. Крауд-упоминания.
5. Справочники и партнёрские бейджи.

Анкоры: микс бренд / URL / безанкор. Точный ВЧ-анкор — редко, не пачкой.

Минусинск: резкий рост арендных, один IP-прогон, анкор «конференции в москве» на 80%. Лечится остановкой и временем, не «разбавлением ещё сотней».

## 6. Хост, ИКС, бренд

ИКС — коррелят, не кнопка. Растёт от полезных страниц, цитирования, брендового спроса, не от покупки ссылок на главную.

Сейчас 10. Пока нет карточки в Справочнике и бренда, скачок до 40 нереален.

Возраст домена не спасает: Яндекс видит «старый URL, слабый хост».

## 7. Региональность

- Регион в Вебмастере: руками, API v4 не ставит. Закрыт 2026-08-20.
- Геозависимый запрос «в москве» усиливается регионом хоста + контентом Москвы.
- Городские посадочные без событий = дорвей, не «региональное SEO».
- NAP единообразен: сайт, Бизнес, 2GIS если есть офис.

## 8. Техника и индекс

- Sitemap уже в Вебмастере (409 при повторной отправке).
- `DUPLICATE_PAGES` = вес режется между `/`, `/events`, пресетами, query-URL.
- Canonical жёсткий. Пагинация и фильтры — политика noindex или canonical на канон.
- Переобход: квота 150/день, каноны после правок.
- Скорость и мобильность — гигиена, не рычаг топа.

## 9. Экосистема Яндекса

| Сервис | Зачем | Статус |
| --- | --- | --- |
| Вебмастер | диагностика, ИКС, переобход | есть, регион не задан |
| Метрика | ПФ, цели, сегмент organic | счётчик есть, цели есть |
| Бизнес / Справочник | коммерческий паспорт, локальная выдача | нет |
| Дзен | информационный трафик, бренд | не заведён как канал продвижения |
| Карты | только если есть офис | не путать с каталогом событий |
| Директ | живые сессии, бренд | опционально, не накрутка органики |

## 10. Свежесть

Запросы с «2026», «осень», «сентябрь» требуют актуальных дат. Просроченный календарь проигрывает даже слабому конкуренту со свежими карточками.

## 11. Спам-фильтры (вето)

Баден-Баден, Минусинск, накрутка ПФ, дорвеи, аффилиат, AGS, накрутка отзывов. Подробности и серый контур — gray.md.

## Как диагностировать за один проход

1. Вебмастер: ИКС, presentProblems, searchable vs excluded.
2. SERP инкогнито, регион Москва: топ-10 по двум ВЧ + сниппеты.
3. Сравнить число ближайших событий на каноне с топ-3.
4. Метрика: organic, отказ и глубина `/city/moskva-1`, цели.
5. Есть ли Бизнес и регион.
6. Только потом — тексты и новые URL.
