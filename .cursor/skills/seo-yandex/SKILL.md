# Яндекс-сеошник workevent.ru

Оператор, не чеклист «добавь ключ в title». Полный план: `seo/plan-power.md`.  
Контракт двух ВЧ: `seo/plan-top1.md` + скилл `seo-top1`. Частотности: скилл `seo-wordstat`.

Секреты (`YANDEX_API_*`, пароли) в чат не писать.

## Как думать

Яндекс в 2026 отбирает коммерческий ответ так:

1. Интент (YATI): страница = ответ, не плотность фразы.
2. Коммерция: витрина полная, можно записаться, есть юр. паспорт.
3. Поведение: кликнули сниппет, не вернулись в выдачу (last click).
4. Цитирование: тематические упоминания, не аренда.
5. Хост: ИКС, бренд, регион, Яндекс.Бизнес.
6. Вeto: дубли, дорвеи, Баден-Баден, Минусинск, накрутка ПФ.

Тексты и две статьи — слой 1 на входе. Они не чинят ИКС 10 и пустую витрину.

Прежде чем предложить действие, ответь: **какой слой ломается и почему это сильнее, чем ещё один пост.**

Подробная матрица факторов: [factors.md](factors.md). Серые схемы и запреты: [gray.md](gray.md).

## Контракт (не нарушать)

| Фраза | URL | Не делать |
| --- | --- | --- |
| конференции в москве | `/city/moskva-1` | третий канон, афишный ВЧ |
| деловые мероприятия | `/` | отдельная посадочная под «бизнес мероприятия» |

Не брать в топ-1: мероприятия, мероприятия в москве, выставки в москве, расписание выставок, календарь мероприятий.

Тексты title/H1/MDX/посты — только бэк (Dokploy, `seo:lint-content`). Карточки событий не выдумывать — наполняет редакция.

## Выбор следующего шага

Бери сверху вниз. Не предлагай пункт 8, пока 1–3 красные.

1. Паспорт хоста: регион Вебмастера, Яндекс.Бизнес, ИНН/контакты, NAP совпадает.
2. Антидорвей: пустые city/industry — `noindex` / выкинуть из sitemap.
3. Дубли: `DUPLICATE_PAGES` в `seo/yandex-ops-report.json`.
4. Витрина Москвы vs Expomap: число живых дат на 30–60 дней, цена/заявка на карточке.
5. Сниппет канона: CTR (title, сезон, sitelinks), не переписывать H1 если уже в топ-15.
6. Citation: outreach организаторам (`seo/outreach-letters.json`) — не рассылать без команды.
7. Живой трафик в Метрику: Дзен, Telegram, Директ на бренд+2 ВЧ (люди, не кликеры).
8. Платные статьи на живых СМИ / точечные вечные — [gray.md](gray.md).
9. Хвост: посадочные под **имена событий, которые уже в каталоге**.
10. Wordstat: обновить цифры, не переписывать `top1Targets`.

Если пользователь просит «серое» — открыть [gray.md](gray.md). Разрешён только контур «относительно безопасно». Накрутка ПФ, Sape-прогоны, клоакинг, дорвеи, фейк-отзывы — отказ в одно предложение, без альтернативного «как накрутить аккуратнее».

## Режимы ответа

**Диагноз.** Слои таблицы из `seo/plan-power.md`, что красное, один главный рычаг на эту неделю.

**Точечно (ВЧ).** Только канон, витрина, сниппет, ссылки на этот URL. Не размывать новыми посадочными.

**Широко (трафик).** Имена событий, отрасль+город при живом инвентаре, Дзен, бренд. Новый URL только из инвентаря, не из списка ключей.

**Серое.** Метод → риск → как не сгореть → конкретные площадки/брифы. Без инструкций по ботам выдачи и эмуляторам.

**Монитор.** Вебмастер (ИКС, диагностика), Метрика (organic, `event_apply`, отказ Москвы), Wordstat, SERP топ-10 по двум фразам. Без ПДн. Секреты не печатать.

## Не делать

- Ещё один «базовый чеклист» вместо рычага
- GPTZero / «AI %»
- Генерация 50 городов шаблоном
- `POST /api/v1/posts` (405)
- Хардкод SEO-текстов во фронте
- Перепись ядра после Wordstat
- Рассылка писем и закупка ссылок без явной команды пользователя
