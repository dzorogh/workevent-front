# Discovery: пробелы относительно 01-discovery.png

## Нет в пакете

- Отдельные оригиналы трёх обложек. В PNG они сгенерированы и уже с плашкой даты.
- Векторный знак WE и wordmark.
- Вектор декоративного «билета».
- Файл шрифта прототипа. В проекте Geist; Inter — запасной кандидат.

## В PNG есть, в старом каталоге не было

- Закладки, вид сетка/список, сортировка — уже добавлены в текущем редизайне, локально.
- «Добавить событие» — публичная форма `/events/new`.
- Короткие отображаемые названия карточек — презентация, не поля БД.

## Как закрываем

- Для `/dev/discovery` вырезаем обложки из эталона и кладём свою плашку даты поверх той же зоны.
- Рабочая `/` берёт живые обложки событий, `object-position: center`, без случайного кропа.
- WE и билет — новые SVG по форме PNG, не текст «WE» в квадрате.
- Шрифт: Geist 400/500/700. Совпадение метрик не обещаем.
