# Редизайн страницы мероприятия

Дата: 2026-09-12  
Репозиторий: `workevent-front`. Бэкенд не меняем.

## Цель

Страница `/event/[id]` в языке каталога (discovery). Главное действие — заявка на Workevent. Все текущие блоки остаются, их можно переставить и усилить.

## Решения

| Тема | Решение |
| --- | --- |
| Язык | Те же токены, что у главной: `#F6F8FC`, `#090D2B`, `#4545EF`, `#657087`, карточки `rounded-[16px]` |
| CTA | Форма заявки в первом экране; сайт организатора вторичен |
| Форма | Цель Метрики `event_apply`, без записи. Клиентская валидация и тост |
| Блоки | Ничего не выкидываем. Теги один раз. Сепараторы убираем |
| SEO | Title/H1/JSON-LD/FAQ/перелинковка как сейчас |
| Закладка | Тот же `localStorage`, что на карточках |

## Композиция

Десктоп: крошки; слева обложка с плашкой даты, галерея, H1, чипы фактов, действия; справа липкая карточка заявки. Ниже на всю ширину: описание и календарь, темы, контакты, карта, похожие, подборки, FAQ, ссылки.

Мобилка: тот же порядок, форма сразу после фактов. Липкая полоска «Оставить заявку» скроллит к `#apply`, прячется когда форма в кадре.
